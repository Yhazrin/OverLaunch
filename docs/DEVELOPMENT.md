# 开发状态

当前源码为 OverLaunch 0.5.0-beta.1。SwiftUI/AppKit 原生界面，OW120Core 管理配置、导入、运行组件、诊断与性能数据；内部可执行文件及本机数据目录沿用 OW120。

首次使用增加设备检查、完整容器验证、启动配置和组件安装引导。此版本仍以已有完整容器为前提；不提供从零安装战网。

## 已验证与待验证

- 核心配置、APFS 导入隔离、运行组件路径、INI/注册表更新、帧统计等有自动测试；用 `./scripts/test.sh` 执行。
- 首屏与导航在本机窗口检查过；滚动条隐藏后仍能纵向滚动。
- 英雄左右浏览、完整菜单键盘操作和真实窄窗口等交互尚需补充验收。
- 游戏可运行的本机结果不等于跨设备支持：实战 120 FPS floor、1% low/P99、HUD 头像白块与长期稳定性仍待验证。
- Developer ID、公证和跨 Mac 首次导入/修复/退出验证未完成，不把当前源码或本机签名包标为稳定发行版。

## 构建与诊断

`./scripts/build.sh` 构建 app，`./scripts/package.sh` 生成 DMG，产物均在 dist.noindex。英雄素材来自固定版本的上游，下载校验脚本不会修改游戏。可通过 `OW120_ROOT` 指定隔离诊断目录。

`scripts/diagnostics/` 提供生产控件布局样张、下拉定位检查与 Metal 窗口预检查；静态样张不能替代桌面交互或真实对局性能测试。设备采样应区分加载、切换英雄、菜单与连续战斗，不伪造或省略长帧。

本机完整历史交接、私人采样和日志不在公共仓库。贡献者用 issue/PR 描述可复现步骤和验证范围，提交前移除账号与个人路径。
